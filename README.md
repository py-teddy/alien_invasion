# Alien Invasion

A Space Invaders–style arcade game built with Python and Pygame while working through *Python Crash Course* by Eric Matthes.

## About
This project was built from scratch to learn object-oriented programming, game loops, and event handling. It includes a player ship, bullets, and an alien fleet.

## How to run
1. Make sure you have Python installed.
2. Install Pygame: `pip install pygame`
3. Run the game: `python alien_invasion.py`

## What I learned
- Structuring a multi-file Python project
- Using Pygame for rendering, events, and collisions
- Refactoring messy code into dedicated functions and classes
